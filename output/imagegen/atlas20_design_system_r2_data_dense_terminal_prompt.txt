A Design System Reference Sheet poster for Atlas20 Research Console, a crypto rotation strategy research platform. Single dark canvas, cool deep slate background #0A0E14 with subtle blue tint (NOT brown).

AESTHETIC DIRECTION: Data-Dense Terminal. High information density, packed grid, visible 1px hairline #1F2937 grid lines separating every cell. Tight whitespace. Smaller font sizes overall: body text 12-13px, labels 9-10px tracked uppercase. JetBrains Mono is dominant, used for ALL labels, numbers, even some UI text. Inter is reserved only for true display headlines. Feels like a Bloomberg terminal, TradingView screener, or a serious quant analyst working tool. Slightly retro-futurist, ascii-grid energy. Components are crisp rectangles with hairline borders, minimal radius 2-4px max.

Top-left: wordmark ATLAS20 in JetBrains Mono Bold uppercase, letter-spacing 0.18em, #F59E0B. Right of it a thin pipe separator and small mono label RESEARCH CONSOLE / DESIGN SYSTEM / v1 / 2026-05.

6 sections arranged in a TIGHT 16-column grid with NARROW gutters.

01 - COLOR PALETTE (compact strip)
10 swatches in a single row, each 56x56, 2px corners. Below each: stacked tiny mono labels, role name uppercase 8px AND hex 9px. Colors:
Background #0A0E14, Surface #111827, Border #1F2937, Text #E2E8F0, Muted #94A3B8, Gold #F59E0B, Violet #8B5CF6, Emerald #10B981, Rose #F43F5E, Cyan #06B6D4. No other colors.

02 - TYPOGRAPHY (compact)
Two columns. Left: Inter Display with H1 36px / H2 24px / H3 18px / Body 13px, smaller than R1. Right: JetBrains Mono with prominent numeric showcase, large numbers 1,247.56% gold, -32.04% rose, plus a TABULAR ALIGNMENT demonstration: column of 6 right-aligned numbers all decimal-aligned, demonstrating mono advantage. Tiny tracked label CURRENT CHAMPION.

03 - COMPONENT LIBRARY (largest section, packed)
Show each component DENSELY with all states in a tight grid:
- Buttons: primary/secondary/ghost x default/hover/active/disabled, 12 buttons in a 4x3 grid, sharp rectangles, 4px radius max.
- Inputs: text/focused/icon/disabled/error/with-helper-text, 6 variants in a 2x3 grid, mono font inside inputs.
- Select closed plus open with 6 options visible.
- Toggle, checkbox, radio, all on/off states.
- Segmented tabs 5 segments.
- Status pills: 6 variants, positive/negative/neutral/pending/warning/info.
- Metric tile DENSE: 4 mini metric tiles in a row, each tiny: label uppercase mono / value mono / delta chip / mini sparkline.
- Data table BIG: 8 rows x 7 columns, Rank / Token / Sector / Weight % / 24h % / 7d % / Volume, header row with sort indicators, alternating zebra striping, one row in hover state, one cell positive emerald, one rose negative, all numbers right-aligned mono.
- Chart container 360x200: multi-line chart, gold strategy line plus dashed gray BTC benchmark line, dense dotted-grid background, full y-axis ticks every 20%, x-axis date labels, crosshair drawn at one point, value tooltip floating.
- Heatmap mini: 6x6 grid of cells colored by intensity cyan-to-gold gradient, values inside in tiny mono.

04 - ICONOGRAPHY (denser)
Row of 12 line icons, 1.25px stroke, sharper geometric style: dashboard, candlestick, table, history, database, file, settings, search, filter, download, refresh, pin.

05 - DESIGN TOKENS (compact)
Spacing scale 2/4/8/12/16/24, radius scale 2/4/6, border scale 0.5/1/2px, no shadow scale. Replace with ELEVATION via border color strip showing borders darkening.

06 - STATUS INDICATORS (replaces motion)
Connection and data-freshness dots: live pulsing emerald, stale amber, disconnected rose, idle slate. With timestamp examples beside each.

OVERALL: tight, dense, hairline-grid, mono-dominant, working-tool energy. Ultra-detailed 4K vector-sharp, terminal/Bloomberg aesthetic. NO lorem ipsum, NO extra colors, NO gradients, NO glow, NO frilly shadows. Sharp rectangles only.

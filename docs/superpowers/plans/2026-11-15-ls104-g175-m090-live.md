# LS104 S050/G175 M090 Live Track Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add and activate an independent LS104 live track with 1.25x H5 long, 0.50x short request, 1.75x gross cap, 4x isolated venue leverage, 0.50 per-leg buffers, and a 0.90 portfolio margin-utilization cap, without modifying LS45-G125.

**Architecture:** A shared track-profile registry identifies the frozen spec, manifest pins, paths, leverage and margin cap. Research target generation scales short requests before the cash-budgeted combiner; live planning/execution/audit consume the same profile. LS45-G125 remains the default and fallback; LS104 gets separate targets, manifest, state, journal and audit files.

**Tech Stack:** Python 3.11, pandas, pytest, Typer/argparse-style project CLI scripts, Bitget UTA execution adapters.

**Spec:** `docs/superpowers/specs/2026-11-15-ls104-g175-m090-live-design.md`

## Global Constraints

- T+1 01:05 UTC execution clock.
- 2/20/50bps are the new track's hard stress points; 100bps is diagnostic only.
- 4x is venue leverage; explicit per-leg margin is governed by 50% buffers.
- 0.90 max margin utilization; 1.75x max gross.
- All existing fail-closed data, manifest, isolated-margin, stop, idempotency and reconciliation gates remain.
- LS45-G125 artifacts and state must not be overwritten.

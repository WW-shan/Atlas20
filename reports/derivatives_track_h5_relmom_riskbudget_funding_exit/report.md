## 一、结论

LS10 在 LS9 的 funding 拥挤退出空头上增加一个入场确认：

> 信号日资产 14D 回报必须低于 BTC 的 14D 回报。

20bps：

- H5 基线：**21.3487x / Sharpe 1.7361 / MDD -33.36%**
- LS10 候选：**22.1461x / Sharpe 1.7567 / MDD -33.54%**
- 空头 open / stop：15 / 4
- 最大 requested/observed gross：**0.0857x / 0.9568x**
- 强平：0

相对动量过滤确实把 LS9 的 365 天滚动最差从 0.7865x 改善到 **0.7946x**，但仍低于 H5 的
0.7970x。同时它把 Sharpe 从 LS9 的 1.7984 降到 1.7567，并把空头贡献集中到 NEAR。
因此 LS10 失败于三个硬门槛：

1. **365 天滚动最差 0.7946x < H5 0.7970x**；
2. **单资产空头贡献 67.62% > 50%，前 3 贡献 104.60% > 80%**；
3. **Top20/2022 DSR 0.9237、全项目 DSR 0.8974**。

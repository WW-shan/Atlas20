## 选择

### 按当前项目硬门

当前 **L125-S025** 仍是最合适的实盘基线：

- 20bps：82.77x / 2.072 / -33.70%；
- 50bps：49.27x / 1.858 / -38.14%；
- 100bps：20.69x / 1.499 / -46.72%，仍低于 50% kill line；
- 0 强平、0 gross breach（G=1.50 口径）。

### 如果只追求 20bps 终值

**L125-S050-G175** 是激进候选：

- 20bps 106.74x，比当前高约 29%；
- Sharpe 2.074，几乎不变；
- MDD -37.81%，比当前差约 4.1pp；
- 50bps 仍高于当前终值，但 Sharpe 更低；
- **100bps MDD -52.77%，越过 50% kill line，判定不能实盘。**

### 如果目标是更低回撤

**L100-S050-G150** 是防御候选：

- 20bps 51.36x / 2.042 / -33.37%；
- 50bps 29.15x / 1.780 / -38.80%；
- 100bps 11.30x / 1.342 / -47.18%；
- 20bps/50bps/100bps 都没有越过 50% MDD；
- 但 100bps 远低于当前 20.69x，且 20bps 终值也比当前低约 38%。

### 1x 多 + 1x 空

**L100-S100-G200 不可作为当前实盘候选：**

- 实际最大目标只有约 1.783x，不是稳定 2x；
- 20bps Sharpe 1.778、MDD -45.22%；
- 50bps MDD -51.05%，已越过 50%；
- 100bps MDD -59.57%、Sharpe 1.009、终值 7.76x；
- 2024 年只有 +32.87%，回撤 -45.22%，说明它更像“2022 危机放大器”，不是稳定的全天候对冲。

## 最终建议

**当前继续使用 L125-S025，7D 重排；不把 0.50x 或 1x 空头直接接到实盘。**

如果你愿意接受更低的长期收益，L100-S050 可以作为独立的“低回撤”研究轨道；如果你愿意只看
低成本的 20bps，L125-S050 可以作为激进研究候选。但两者都必须完成：

- 3x short-adverse funding；
- 50bps/100bps 成本；

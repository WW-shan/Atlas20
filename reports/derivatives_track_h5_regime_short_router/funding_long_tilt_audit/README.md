# H5 long-leg funding tilt feasibility audit

只读审计，不新增 trial。

- 1,053 个 H5 holding-events，覆盖 511 个目标事件日；
- 325 个 holding-events 的 7D funding 位于 PIT Top20 上三分之一且为正；
- 256/511 个目标事件日至少有一个 crowded leg；
- 在触发日，若把 crowded leg 减半，释放的 gross 中位数为 **31.25%**，90 分位为 50%；
- crowded 名称中常见 NEAR、XRP、SOL、SHIB、DOGE、LTC、ZEC 等，说明该风险层不是单一资产事件。

结论：触发频率和释放权重都足够大，值得预注册一次“crowded leg 减半 + 同书再分配”试验。

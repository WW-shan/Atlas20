# Atlas20 候选 LS16：LS12 + 5% NAV no-trade region

日期：2026-11-12  
候选：`PR2026-11-LS16-H5-REGIME-SHORT-NOTRADE5`  
状态：**rejected（稳健性失败）**  
实盘：**不接；当前 `PR2026-10-D-L125-V2` 不变**

## 一、结论

LS16 验证了 no-trade region 可以修复成本尾部，但不能通过路径稳健性：

- 2/20/50/100bps 的终值和 Sharpe 全部高于同成本 L125；
- 100bps 为 **15.4488x / 1.3536 / -49.12%**，同时通过收益、Sharpe、MDD 50% kill line；
- 20bps 累计费用从 LS12 的 2.7745 降到 **2.2248（-19.8%）**，成交数从 2,524 降到 1,537；
- 但删除 2022 后为 **44.9539x < L125 50.0330x**；
- 45 个月初路径切片只有 **23/45** 三项同时通过；
- 2023-03 至 2024-08 的起点上，LS16 最大回撤比基线差 **2.34–7.69pp**；
- 2024-04 至 2024-08 的路径终值和 Sharpe 也低于基线。

因此 LS16 是有效的**成本控制机制**，但不是足够稳健的组合。按预注册不扫描 1%/2.5%/7.5%/10% 容差，不改成只对多头或只对空头应用容差；该家族停止。

## 三、机制

对已存在的同方向仓位：

```text
distance = abs(target_notional - current_notional)
band = 0.05 * equity

if distance <= band:
    no trade
else:
    trade only to target_notional - sign(target-current) * band
```

强制精确执行：

- 新开仓；
- 目标为零或资产退出；
- 多空反手；
- stop、funding、强平和 Top20 约束；
- 当前或 projected gross 超过 1.50x 时，整个事件放弃容差并恢复精确目标。

# 双边轮动第六轮：Bottom-Quincile + 20% 强制止损（2026-11-10）

## 结论

**最强研究候选，但仍未通过全部预注册门槛；不接实盘。**

预注册文件：`docs/superpowers/specs/2026-11-10-cross-sectional-basket-stop-round6-design.md`。

规则：H5 多头 ×1.25；Top20 中 14D 最弱 4 个可交易、非 H5 多头持仓，等权做空，总空头 0.25x；每 7 天再平衡，T+1 +3h；每条空头腿在入场价 adverse 20% 处逐小时 mark 止损。

## 20bps 主口径

| trial | 终值 | Sharpe | MDD | 强平 | 止损次数 |
|---|---:|---:|---:|---:|---:|
| `PR2026-10-D-L125` | 40.2200x | 1.7330 | -40.6506% | 0 | 0 |
| `PR2026-11-RS6-X-WEAK4-STOP20` | **51.8010x** | **1.8918** | **-42.5916%** | **0** | 50 |

20bps 通过：终值 +28.8%，Sharpe +0.159，MDD 只差 1.94pp，且止损把原本的 3 次强平全部转为可控的 50 次小损失。

## 成本与 funding 压力

| trial | 20bps | 50bps | 100bps | 100bps MDD |
|---|---:|---:|---:|---:|
| L125 基线 | 40.2200x | 27.3725x | **14.3794x** | -50.0229% |
| RS6 | 51.8010x | **28.3854x** | 10.3786x | **-54.0625%** |

- 50bps 仍高于基线（28.39x vs 27.37x），通过；
- 100bps 低于基线且 MDD 越过 50%，**失败**；
- 3x short-adverse funding：49.6029x / Sharpe 1.8723 / MDD -42.9484% / 0 强平；相对零 funding 基线 44.1253x 仍通过，但 funding 仍是 Binance proxy/skip。

## 判定

| 条件 | 结果 |
|---|---|
| 20bps 终值 > 基线 | 通过 |
| 20bps Sharpe ≥ 基线 | 通过 |
| 20bps MDD ≤ 基线 +5pp | 通过 |
| 0 次强平 | 通过 |
| 50bps 终值 > 基线 | 通过 |
| 100bps MDD ≤ 50% | **失败** |
| 移除 2022 后仍 > 基线 | **失败** |
| PBO ≤ 0.5 | 通过 |
| 接实盘 | **拒绝** |

因此 R6 是有价值的 provisional research candidate：它证明了 bottom-quintile 空头篮子 + STOP20 能把强平尾部转成可管理损失，并显著提高全样本收益；但 100bps 成本和 2022 依赖仍不合格。不能因为 20/50bps 好看就上线。

## 边界

- 没有修改实盘执行器、plist、systemd 或当前 H5 多头账本；
- 没有接空头实盘；
- Binance funding 仍是 proxy/skip，不是 Bitget 精确历史；
- 2026-09-22 后 OOS 仍不足 12 个月；
- 下一步若要继续，必须预注册一个**降低换手/成本**的新机制，不能继续扫 stop、buffer 或篮子大小。
